# Wordix — 单词学习系统（单机版）

一个基于 Python + Tkinter + SQLite 开发的**本地单词学习软件**，
支持词根词缀记忆、单词录入、单词练习、词表管理，纯本地运行，无需联网，数据永久保存。

---

## ✨ 版本信息
**当前版本：v1**  
**内容：**
- 单词录入、持久化存储
- 所有数据本地 SQLite 存储，重启不丢失
---

## 🎯 功能介绍
### 1. 单词录入
- 录入单词、音标、词性、中文释义
- 选择等级：小学/初中/高中/四级/六级/托福/雅思
- 支持英文例句 + 中文翻译

### 2. 词库列表
- 单词列表：单词、音标、词性、中文释义

## 新增功能说明
### 1. 单词查找功能
   词库管理页面顶部添加了输入框 + 搜索按钮
   回车即可触发搜索，操作更便捷
   找到单词：自动在列表中显示并高亮选中
   未找到：弹出提示框告知
### 2. 分页功能
   默认每页显示 10 条单词
   支持上一页 / 下一页翻页
   实时显示：当前页/总页数 + 总单词数
   数据库使用 LIMIT/OFFSET 分页，性能更优

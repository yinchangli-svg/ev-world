# Wordix — 单词学习系统（单机版）

一个基于 Python + Tkinter + SQLite 开发的**本地单词学习软件**，
支持词根词缀记忆、单词录入、单词练习、词表管理，纯本地运行，无需联网，数据永久保存。

---

## ✨ 版本信息
**当前版本：v1**  
**内容：**
- 单词录入、持久化存储
- 所有数据本地 SQLite 存储，重启不丢失

## 🎯 功能介绍
### 1. 单词录入
- 录入单词、音标、词性、中文释义
- 选择等级：小学/初中/高中/四级/六级/托福/雅思
- 支持英文例句 + 中文翻译

### 2. 词库列表
- 单词列表：单词、音标、词性、中文释义

## v1.1 新增功能说明
### 1. 单词查找功能
- 词库管理页面顶部添加了输入框 + 搜索按钮
- 回车即可触发搜索，操作更便捷
- 找到单词：自动在列表中显示并高亮选中
- 未找到：弹出提示框告知
### 2. 分页功能
- 默认每页显示 10 条单词
- 支持上一页 / 下一页翻页
- 实时显示：当前页/总页数 + 总单词数
- 数据库使用 LIMIT/OFFSET 分页，性能更优

## v1.2 新增功能说明
### 1. 词库等级选择功能
- 新增等级筛选下拉框，默认选中第一个：小学 3-4 年级
- 切换等级后，只显示当前等级的单词
- 搜索功能只在当前等级内搜索
### 2. 单词录入页面同步等级
- 等级下拉框灰色不可选
- 等级自动同步词库选择的内容
- 保存单词时自动存入当前选中的等级
### 3. 全局等级同步
- 等级切换后录入页面自动同步
- 数据完全按等级隔离，不会混乱

## v1.3新增功能说明

### 1. 导出
- 导出当前等级下所有单词
- 自动生成 Excel 文件，可选择保存路径
- 包含：单词、英音标、美音标、词性、释义、例句、翻译
### 2. 导入
- 根据模版内容，填写要导入的单词列表，选择文件，导入
- 自动导入到当前等级
- 自动跳过重复单词，统计成功 / 失败数量
### 3. 下载导入模板（蓝色链接）
- 点击即可下载标准 Excel 导入模板
- 列格式完全匹配系统，直接填写即可导入

## v1.4 两大核心新功能详解
### 一、单词背诵 Tab（记忆模式）
自动读取当前等级全部单词，随机抽取生成记忆卡片
卡片分层展示：默认只显示英文单词，点击「翻面查看释义」展开完整信息
英音标、美音标、词性、中文释义、英文例句、例句翻译
配套功能：
朗读当前单词发音
一键切换下一个随机单词
适配等级联动：顶部切换等级，背诵池自动更换对应单词
空词库友好提示，无单词时提示去录入页面添加
### 二、拼写测试 Tab（听写自测）
只展示中文释义，用户在输入框默写英文单词
提交自动校对，区分对错：
正确：绿色对勾提示，自动 1.2 秒跳转到下一题
错误：红色提示并展示标准答案
实时统计正确率：正确 / 错误计数，支持一键重置统计
快捷键：输入框按回车直接提交答案
朗读标准答案、切换题库、重置分数功能齐全
同步优化修复（兼容旧版本）
数据库连接新增 check_same_thread=False，彻底修复 database is locked 报错
词库管理 Treeview 新增英音标、美音标两列，完整展示所有字段
窗口尺寸放大至 960×760，适配新增两个标签页不拥挤
统一字体字号规范，区分大标题、按钮、正文，视觉更舒适
所有等级下拉全局联动：词库、录入、背诵、拼写测试共用一套等级筛选
分页、搜索、导入导出、Excel 模板、单词朗读全部保留原有逻辑，无功能丢失

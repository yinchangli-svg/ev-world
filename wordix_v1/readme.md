# Wordix — 单词学习系统（单机版）

一个基于 Python + Tkinter + SQLite 开发的**本地单词学习软件**，
支持词根词缀记忆、单词录入、单词练习、词表管理，纯本地运行，无需联网，数据永久保存。

---

## ✨ 版本信息
**当前版本：v1**  
**内容：**
- 单词录入、持久化存储
- 所有数据本地 SQLite 存储，重启不丢失
---

## 🎯 功能介绍
### 1. 单词录入
- 录入单词、音标、词性、中文释义
- 选择等级：小学/初中/高中/四级/六级/托福/雅思
- 支持英文例句 + 中文翻译

### 2. 词库列表
- 单词列表：单词、音标、词性、中文释义

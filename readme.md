# ev-world · 免费英语学习工具集

一个面向中小学英语学习的**免费、开源、无广告**学习工具集，第一阶段专注英语核心能力建设，首期聚焦 **单词记忆 + 智能练习** 功能。

---

## 🌟 项目简介

ev-world 旨在建设一个免费的学习工具集，第一个阶段围绕英语学习，第一部分功能是单词记忆和练习。

作者曾经亲自报名了一些英文课程，也给孩子报名了价格不菲的英文课程，发现目前中小学阶段英语学习的一个重要基础——**单词短语的掌握**。
这部分好比烹饪的食材，没有它完成不了英语学习，乃至英语考试这场筵席。

所以将获得的一些知识和经验固化下来，提炼分享出来。个人能力有限，当是抛砖引玉，希望有志同道合的伙伴加入，
让孩子们的单词学习不那么乏味，给家长节约一些时间、一点金钱。

wordix 是一个单机的单词工具
---

## 🛠 技术栈
- Python 3.x
- Tkinter（GUI 界面）
- SQLite（本地数据库）
- 纯单机、无依赖、开箱即用

---

## 🎯 使用场景
- 学生背单词
- 词根词缀记忆法学习
- 英语教师自制词表
- 个人单词本本地管理
- 无需联网的隐私优先学习工具

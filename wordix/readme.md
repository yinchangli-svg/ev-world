wordix 是一个单机的单词工具
---

## 🛠 技术栈
- Python 3.x
- Tkinter（GUI 界面）
- SQLite（本地数据库）
- 纯单机、无依赖、开箱即用

---

## 🎯 使用场景
- 学生背单词
- 词根词缀记忆法学习
- 英语教师自制词表
- 个人单词本本地管理
- 无需联网的隐私优先学习工具

---

## 🎯 功能列表
- 首页 展示1、软件摘要，2、设置信息：词库信息，可以选择词库，3、功能菜单：开始学习、单词录入、词库管理按钮
- 开始学习 背单词页面，单词信息，
- 单词练习  提供单词的练习模式（补全单词）
- 单词录入 
- 词库管理

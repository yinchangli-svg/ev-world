# Wordix — 单词学习系统（单机版）

> 一个基于 Python + Tkinter + SQLite 开发的**本地单词学习软件**，支持词根词缀记忆、单词录入、背诵练习、拼写测试、单词本管理，纯本地运行，无需联网，数据永久保存。

---

## ✨ 核心特性

- 🎯 **完全离线**：所有数据本地 SQLite 存储，无需网络连接
- 💾 **数据持久化**：重启不丢失，支持导入导出
- 🎨 **友好界面**：清晰的 Tab 分页设计，操作简单直观
- 🔊 **发音支持**：集成 TTS 语音朗读功能
- 📊 **分级管理**：小学到雅思 9 个等级分类
- 📝 **智能单词本**：自动收集错题 + 手动添加重点单词

## 🚀 快速开始

### 环境要求

- Python 3.6+
- 支持平台：Windows / macOS / Linux

### 安装步骤

#### 1. 安装 Python

访问 [Python 官网](https://www.python.org/downloads/) 下载并安装 Python 3.6 或更高版本。

#### 2. 安装依赖

pip install pandas openpyxl pyttsx3
**依赖说明：**
- `pandas`：数据处理和 Excel 导入导出
- `openpyxl`：Excel 文件读写支持
- `pyttsx3`：离线文本转语音（TTS）

#### 3. 运行程序
cd wordix 
python3 word_app.py

## 📖 使用指南

### 功能概览

Wordix 包含 6 个主要功能模块：

| 模块 | 功能说明 |
|------|----------|
| 🏠 首页 | 系统介绍和功能清单 |
| ✏️ 单词录入 | 添加新单词到词库 |
| 📚 词库管理 | 浏览、搜索、分页、导入导出 |
| 🧠 单词背诵 | 卡片式记忆学习（有序遍历） |
| ✍️ 拼写测试 | 听写自测，检验掌握程度 |
| 📖 单词本 | 重点单词收藏与复习 |

### 详细操作

#### 1️⃣ 单词录入

1. 切换到「单词录入」Tab
2. 填写单词信息：
   - 单词（必填）
   - 英音标 / 美音标（可选）
   - 词性（可选）
   - 中文释义（必填）
   - 等级（自动同步词库管理的选择）
   - 英文例句（可选）
   - 中文翻译（可选）
3. 点击「🔊 朗读单词」可以听到发音
4. 点击「保存单词」完成录入

#### 2️⃣ 词库管理

**等级切换**
- 在顶部下拉框选择要查看的等级
- 切换后自动刷新单词列表

**搜索单词**
- 在搜索框输入单词
- 按回车或点击「🔍」按钮
- 找到后会自动高亮显示

**分页浏览**
- 每页显示 10 个单词
- 使用「上一页」/「下一页」翻页
- 底部显示当前页码和总单词数

**导入导出**
- 📥 导出：将当前等级所有单词导出为 Excel
- 📤 导入：从 Excel 文件批量导入单词
- 🔗 下载模板：获取标准导入模板

**朗读单词**
- 双击单词或按回车键可朗读发音

#### 3️⃣ 单词背诵

1. 切换到「单词背诵」Tab
2. 点击「加载词库」加载当前等级的所有单词
3. 卡片默认显示英文单词
4. 点击「翻面查看释义」查看完整信息
5. 使用「上一个」/「下一个」顺序翻阅单词
6. 点击「🔊 朗读单词」听发音
7. 遍历完所有单词后会提示已达末尾

**特点**：
- ✅ 有序遍历，不会重复
- ✅ 边界保护：首单词禁止上翻，末单词禁止下翻
- ✅ 完整展示：音标、词性、释义、例句、翻译

#### 4️⃣ 拼写测试

1. 切换到「拼写测试」Tab
2. 点击「加载题库」加载当前等级的所有单词
3. 查看中文释义，在输入框中输入英文单词
4. 按回车或点击「提交答案」
5. 系统自动判断对错：
   - ✅ 正确：绿色提示
   - ❌ 错误：红色提示，显示正确答案，**自动加入单词本**
6. 实时查看正确/错误统计
7. 可随时点击「重置统计」清零
8. 使用「上一题」/「下一题」切换题目

**特点**：
- ✅ 有序遍历，每题仅计分一次
- ✅ 答错自动收录到单词本
- ✅ 支持前后翻页复习

#### 5️⃣ 单词本 🆕

**添加单词**
- 自动添加：拼写测试答错时自动加入（备注"拼写测试错题"）
- 手动添加：点击「➕ 添加单词」按钮，输入单词和备注

**学习模式**
1. 切换到「📖 单词本」Tab
2. 点击「加载单词本」查看所有收藏的单词
3. 使用「上一个」/「下一个」翻阅
4. 点击「翻面查看释义」查看详细信息：
   - 英音标 / 美音标
   - 词性
   - 中文释义
   - 英文例句 + 翻译
   - 备注信息
   - 添加时间
5. 点击「🔊 朗读单词」听发音

**管理单词**
- ✅ 已掌握：标记单词已掌握并从列表中移除
- 🗑️ 从单词本删除：直接删除该单词
- 实时显示单词总数

**使用场景**：
- 📝 收集拼写测试错题
- ⭐ 手动添加考试重点词汇
- 🔖 标记易混淆、难记忆的单词
- 📚 创建个人专属的高频词汇集

## 💡 常见问题

### Q1: 提示 "database is locked" 怎么办？

A: 此问题已在 v1.3.1 修复。请确保使用最新版本，数据库连接已添加 `check_same_thread=False` 参数。

### Q2: 如何备份我的单词数据？

A: 有两种方式：
1. 使用「导出」功能将单词导出为 Excel 文件
2. 直接复制 `wordix.xdb` 数据库文件

### Q3: pyttsx3 在 macOS 上无法发音或有异步问题？

A: macOS 上 pyttsx3 可能存在兼容性问题。可以尝试：
pip install pyobjc
